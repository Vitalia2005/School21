## Part 5. Использование команды sudo

sudo usermod -aG sudo useradm

logout login

sudo (Substitute User DO) — это утилита, предназначенная для управления привилегиями. Она позволяет пользователю работать с обычными правами (безопасно) и повышать их до уровня суперпользователя (root) только для выполнения конкретной задачи. В отличие от прямого входа под root, sudo записывает в системный журнал (/var/log/auth.log), кто именно и какую команду выполнил. Это критически важно для безопасности в компаниях. Администратор может настроить sudo так, чтобы конкретный пользователь мог выполнять только одну определенную команду (например, только перезагружать сервер), не давая ему полного контроля над системой.

* Используя команду ps, покажи наличие процесса sshd. Для этого к команде нужно подобрать ключи. В отчёте объясни значение команды и каждого ключа в ней. Перезагрузи систему.

![sshd](assets/Screenshot 2026-05-11 021617.png)

ps aux | grep sshd

a (all): Показывать процессы всех пользователей, а не только мои

u (user): Выводить подробную информацию (кто запустил, сколько памяти ест)

x: Показывать процессы, не привязанные к конкретному терминалу

| grep sshd: Передает весь список процессов фильтру, который оставит только строки, где есть слово sshd

sudo reboot

* Вывод команды netstat -tan должен содержать tcp 0 0 0.0.0.0:2022 0.0.0.0: LISTEN В отчёте объясни значение ключей -tan, значение каждого столбца вывода, значение 0.0.0.0.

sudo apt install net-tools -y

netstat -tan

выводим и видим что там еще 22 и узнаем что надо еще отключить сокет: В Ubuntu 24.04 по умолчанию используется механизм Socket Activation. Это означает, что порт прослушивается системным сокетом (ssh.socket), а не самой службой SSH. Чтобы изменения в конфигурационном файле (смена порта на 2022) вступили в силу, необходимо отключить ssh.socket и перезапустить службу ssh.service, которая считывает настройки напрямую из файла sshd_config


вводим:

sudo systemctl stop ssh.socket

sudo systemctl disable ssh.socket

sudo systemctl restart ssh


опять вводим команду нетстат и видим заветный результат 

![netstat](assets/Screenshot 2026-05-11 023347.png)


Значение ключей -tan:

-t (tcp): Показывать только TCP-соединения (SSH работает по TCP)

-a (all): Показывать как активные соединения, так и порты, которые просто слушают

-n (numeric): Показывать адреса и порты цифрами (например, 2022 вместо названия службы ssh)

Значение столбцов вывода:

Proto: Протокол (tcp)

Recv-Q / Send-Q: Очереди получения и отправки данных (в норме там 0)

Local Address: Адрес и порт компьютера, который принимает соединения

Foreign Address: Адрес удаленного устройства. : означает, что соединение еще не установлено

State: Состояние порта. LISTEN означает, что программа запущена и готова принять входящий звонок

Значение 0.0.0.0:
Этот адрес означает все доступные сетевые интерфейсы. Если на компьютере есть и Wi-Fi, и проводная сеть, и петлевой интерфейс lo, то SSH будет ждать подключения на каждом из них.
